# 決定の記録（ADR）

つくりを決めたときの記録です。コードとコミットから読み取れる「決めたこと」と「その結果」を書きます。当時に比べた案・経緯で、記録に残っていないものは書いていません。

| ------------------------------------------- | -------------------------------------------------------------------- |

| [0002](0002-small-aws-footprint.md)         | AWS の構成は S3・CloudFront・Lambda・DynamoDB だけにする             |
| [0003](0003-storybook-on-another-origin.md) | Storybook はキャンバスと別のオリジンで配り、橋渡しだけでやり取りする |
| [0004](0004-derive-thread-status.md)        | スレッドの状態は保存せず、持っている項目から決める                   |

## 足し方

- 次の番号で `NNNN-<短い名前>.md` を作り、この表に足す
- 書くのは「状況（事実）・決めたこと・結果（得たもの・引き受けたもの）」。推測は書かない。分からないことは「記録に無い」と書く
- 決め直したときは、前の記録を消さずに「NNNN で置き換えた」と書き足す
