# 0004 スレッドの状態は保存せず、持っている項目から決める

## 状況

- スレッドには `open`・`ai-fixed`（AI が直したと知らせた。確認待ち）・`resolved` の状態がある
- `ai-fixed` は、`resolved` だけを持っていたところへ後から足した

## 決めたこと

- 状態は項目として保存しない。解決の状態（`resolved`）と AI 修正済みの印（`aiFixedAt`）から決める（`api/domain/model/comment/comment.ts`）
- 印を持つ前のコメントは、印なしとして読む

## 結果

- 状態を足しても、前からのデータを書き換えずに読める。API の `resolved`・`PUT .../resolution` はそのまま動く
- 状態と元の項目が食い違うことがない（元の項目しか無い）
- 状態で絞る読み込みは、読んでから絞る（状態の索引は無い）
