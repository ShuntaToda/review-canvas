# 0003 Storybook はキャンバスと別のオリジンで配り、橋渡しだけでやり取りする

## 状況

- Storybook の中身（ストーリーのコード）は、ブランチごとに誰でも置き換えられる
- キャンバスの画面は、API を呼ぶためのログインのトークンを持つ

## 決めたこと

- キャンバス・API と Storybook は、別の CloudFront の配信（別のオリジン）で配る。手元でも別のポート（4100 と 4102）で配る
- 画面と Storybook は、Storybook の `iframe.html` に差し込む橋渡し（`src/features/review/bridge/`）と `postMessage` だけでやり取りする。橋渡しは、受け付けるキャンバスのオリジンを決めておく
- バケットのポリシーでも、画面の配信は `sb/*` を読めず、Storybook 用の配信は `sb/*` の外を読めないようにする

## 結果

- ストーリーのコードから、キャンバスのトークン・保存した値・DOM に届かない
- 画面は iframe の中を直に読めないので、要素の位置・手がかりは橋渡しが測って送る
- 橋渡しのファイルを置く・差し込む手順が要る（`pnpm run build:bridge`・置くスクリプト）

くわしくは [security.md](../security.md)。
